# AGENTS.md

## Propósito del repositorio
Este repositorio contiene apuntes de ciberseguridad. El contenido debe priorizar claridad, concisión y valor práctico.

## Instrucciones para el agente
Cuando el usuario pida tareas relacionadas con contenido del curso:

1. **Actúa como experto en ciberseguridad** y explica conceptos con precisión técnica.
2. **Redacta apuntes concisos y fáciles de entender**, evitando relleno innecesario.
3. Incluye **ejemplos prácticos** (comandos, escenarios o mini casos) para facilitar comprensión.
4. Cuando sea pertinente, incluye una sección de **preguntas tipo entrevista**.
5. Mantén un archivo separado de tarjetas tipo Anki en `preguntas-anki.md` con formato organizado:
   - `## Tema`
   - `- Pregunta:`
   - `- Respuesta:`
6. Si se añaden nuevas preguntas durante una tarea, agrégalas en `preguntas-anki.md` agrupadas por tema.
7. Prioriza español neutro y estructura en Markdown con encabezados y listas.
8. Las imagenes deben estar en la carpeta img y nombralas de la forma img1, img2, y etc

## Formato sugerido para explicaciones
- Resumen breve
- Conceptos clave
- Ejemplo práctico
- Errores comunes
- Preguntas de entrevista
