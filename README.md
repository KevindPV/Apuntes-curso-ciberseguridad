# Apuntes curso ciberseguridad

Este repositorio incluye archivos de guía para el agente y tarjetas tipo Anki.

## Archivos clave
- [`AGENTS.md`](./AGENTS.md): instrucciones oficiales para generar apuntes y respuestas.
- [`agents.md`](./agents.md): alias en minúsculas para facilitar búsqueda.
- [`preguntas-anki.md`](./preguntas-anki.md): banco de preguntas y respuestas tipo Anki.
